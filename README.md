# BigfootSignature

Email signature maker for Bigfoot Group. Type your name, title, email and phone numbers, then download or copy the finished signature as a PNG.

Live page: https://sufi-bigfoot.github.io/BigfootSignature/

- `index.html` – the page (no build step)
- `background.png` – signature banner (2038 × 772) the text is drawn onto

Text uses Segoe UI Bold, so make signatures on a Windows PC for an exact match.
